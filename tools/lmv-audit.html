Livsmedelsverket audit

Checks every food in the app against the food database. Runs on your device — nothing is uploaded.

1Download the whole database

Open Sök näringsinnehåll and use Ladda ner Livsmedelsdatabasen — the link at the bottom of the search page, or the icon under the search field. That gives you every food and every nutrient in one Excel file.

Don't use the API for this. It returns one page of food names at a time and needs a separate request per food to get the nutrients, which is thousands of requests for the same data the single file already contains.

2Open the file here

Pick the file you just saved. Excel (.xlsx), CSV and JSON all work, and it is read on this device — nothing is uploaded.

Or fetch an address directly

Only useful if you have a single URL that returns foods with their nutrients. A browser can also only read another site's data if that site allows it, so this often fails where step 2 works.
