Livsmedelsverket audit

Checks every food in the app against the food database. Runs on your device — nothing is uploaded.

1Fetch the data

Paste the address of a Livsmedelsverket endpoint that returns the foods with their nutrients, then press Fetch. You can find the exact address on the API documentation page.

This may not work: a browser can only read another site's data if that site allows it. If it fails, use step 2 instead — that always works.

2Or open a downloaded file

Open the address above in a normal browser tab and save the result, then pick the saved file here. JSON and CSV both work.
