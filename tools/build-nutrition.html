Build nutrition data

Turns the food database export into nutrition-data.js. Runs on your device — nothing is uploaded.

1Get the Livsmedelsverket export

Livsmedelsverket's, and only that one. Open Sök näringsinnehåll and use Ladda ner Livsmedelsdatabasen. It is the same file the Swedish audit takes, read the same way and matched through the same confirmed list, so the two cannot disagree.

The Danish and American databases do not go here. Frida's workbook belongs in the Danish audit and USDA's JSON in the American audit. What comes back from those is a small nutrition-*.js, and that goes in step 3 below — not here.

2Open the file here

Excel (.xlsx), CSV and JSON all work.

3The audit files (optional)

Everything below Livsmedelsverket on the ladder — nutrition-frida.js, nutrition-usda.js, nutrition-manual.js. Leave this empty and the copies already in the repo are used, which is what you want when nothing has changed since they were committed.

Add them here to build straight from a round you have just finished, without committing first. Each file replaces the repo's copy of that source entirely, because a generated file is meant to be the whole of it — so a short one is a warning, not a merge.

4Save it into the repo

Download it and put it in the project root as nutrition-data.js, replacing what is there. It is generated — nothing in it is meant to be edited by hand.
