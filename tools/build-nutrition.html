Build nutrition data

Turns the food database export into nutrition-data.js. Runs on your device — nothing is uploaded.

1Get the export

The same file the audit takes. Open Sök näringsinnehåll and use Ladda ner Livsmedelsdatabasen.

Already have it open for the audit? Use the same file — this page reads it the same way and matches through the same confirmed list, so the two cannot disagree.

2Open the file here

Excel (.xlsx), CSV and JSON all work.

3Save it into the repo

Download it and put it in the project root as nutrition-data.js, replacing what is there. It is generated — nothing in it is meant to be edited by hand.
